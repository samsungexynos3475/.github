# 📱 Samsung Exynos 3475 Android Development
Samsung's Exynos 3475 SoC tree revived. Based off the Exynos3475 source code: https://github.com/Exynos3475

Currently focus on LineageOS based ROM. To get started with your own builds, check out local manifests: https://github.com/samsungexynos3475/local_manifests

**IMPORTANT:** Building requires patching. You **must** apply framework and hardware fixes before compiling, which can be found at: https://github.com/samsungexynos3475/android_patches

# Supported Devices
- Samsung Galaxy J2 2015 (`j2lte`)

# Supported OS
- LineageOS 17.1 (Android 10)
- LineageOS 18.1 (Android 11)
- LineageOS 19.1 (Android 12L)
